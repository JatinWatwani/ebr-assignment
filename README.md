# Ring Pop® Candy Website — 1:1 Carbon Copy

An authentic, identical **1:1 Carbon Copy** of [https://ringpopcandy.com/](https://ringpopcandy.com/).

## 🍬 Key Features
- **Authentic Drag & Toss Footer Candies (`MFRFooterCandiesV3`)**: Interactive multi-body physics candies powered by GSAP & Draggable with realistic gravity, floor bounce, stack collisions, and cursor flick/toss velocity.
- **GSAP ScrollTrigger Stacking Sections (`MFRStackingSection`)**: Card pinning, stacking transitions, and icon parallax scrubber.
- **Exact Typography**: `Ringold Soft` (woff2) and all weights of `Greed Standard` (300–800) and `Greed Extended` (Regular–Heavy).
- **Comprehensive Route Matrix**: Homepage, Shop, Weddings, Product Details, ColorFest, Party Pack, Content Hub, About Us, Contact.
- **Optimized for Vercel**: Clean URLs, global edge routing, and immediate asset delivery.

## 🚀 Running Locally
```bash
node server.js
```
The site will be available at `http://localhost:3000/`.
